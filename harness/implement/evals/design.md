# 設計評価（Design Evaluation）

実施タイミング: `evaluate.sh` が `risk: high` を返したとき、または実装前に大きな設計判断をしたとき。
評価者: evaluator（Level 2）→ 人間（Level 3）

| ID | 基準 | 判定の根拠にするもの |
|---|---|---|
| D-1 | 設計が `specs/<機能>/requirements.md` の各要件に対応している | 要件 ID ごとの対応箇所 |
| D-2 | 既存の設計・データモデルと矛盾しない | 既存コードの該当箇所 |
| D-3 | 再実行・二重実行で結果が壊れない（冪等性） | 処理の流れとキー・制約 |
| D-4 | 障害時に再開・復旧できる | 例外処理・トランザクション境界 |
| D-5 | 認証・認可を弱めていない | 権限チェックの位置 |
| D-6 | 未確定の業務ルールを推測で埋めていない | 推測した箇所の列挙（あれば BLOCKED） |
