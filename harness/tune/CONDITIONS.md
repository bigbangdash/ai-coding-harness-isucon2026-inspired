# 競技条件

大会ごとに書き換える。認証情報は書かない（環境変数名だけ書く）。
コマンドは `policies/competition.toml` の `[commands]` に設定する。

## 競技時間

- 開始から 480 分（Runner が管理する。残り時間は `python3 harness/tune/runner/lifecycle.py status`）
- 終了 40 分前から終盤（新規改善をやめ、再起動・永続性を確認する）
- 最終スコアは **最後に実行したベンチマークの結果**（最高スコアではない）

## レギュレーション

- （大会のマニュアルから転記する）
- 例: ベンチマーカーの改変・負荷の検出回避は禁止
- 例: 再起動後もアプリが動作し、データが保持されていること

## 環境

| 項目 | 値 |
|---|---|
| 競技サーバー | （例: isu1 / isu2 / isu3。SSH 設定名） |
| 改善対象 | `app.workdir`（competition.toml） |
| ベンチマーカー | `commands.benchmark` |
| 認証情報 | 環境変数 `ISUCON_*`（ファイルに書かない） |

## 開始時にやること

1. `isucon` スキルを読み、道具の使い方を確認する
2. 環境・ログ・マニュアルを調べる
3. 何も変えずにベースラインを測定する（`benchmark.py --hypothesis "baseline"`）
