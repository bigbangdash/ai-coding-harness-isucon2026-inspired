# 請求書の消費税計算

> 承認されたかどうかは `harness/implement/approved.sha256` が正。この文書には書かない。

## 背景

請求書（適格請求書）に記載する消費税額を計算する。経理担当が請求書を発行するときに使う。
適格請求書では、消費税額の端数処理は「1 つの請求書につき、税率ごとに 1 回」と決まっている。

## 要件

| ID | 要件 |
|---|---|
| REQ-1 | 明細は「単価（税抜・円）」「数量」「税率」を持つ。税率は 10%（標準）と 8%（軽減）だけ |
| REQ-2 | 消費税額は、税率ごとに明細の税抜金額を合計し、その合計に税率を掛けて求める（明細ごとには端数処理しない） |
| REQ-3 | 1 円未満の端数は切り捨てる |
| REQ-4 | 結果として、税率ごとの「税抜合計」「消費税額」と、請求書全体の「税抜合計」「消費税合計」「税込合計」を返す |
| REQ-5 | 数量・単価が負、または未対応の税率の明細はエラーにする |

## 対象外

- 値引き・返品の明細（Q-1 の回答により本機能では扱わない）
- 税込単価での入力
- 請求書の発行・保存・送付
